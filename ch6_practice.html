풀이

  1. 같은 단서 조합이면 모델은 늘 같은 답을 냅니다. 그래서 데이터에서 정답이 갈렸던 조합(3-3)은 어떤 모델도 다 맞힐 수 없습니다.
  2. 데이터에 나온 조합은 676개뿐이고, 나머지 8,000여 개는 한 번도 본 적 없는 조합입니다. 거기서는 모델의 "성격"대로 답이 갈립니다: 시아는 무게를 더하고, 모아는 질문 길을 따라가고, 하루는 나무 100그루의 합으로 답합니다.
  3. 확신(확률)은 "그 정답일 가능성"에 대한 모델 스스로의 계산입니다. 높다고 꼭 맞는 것은 아닙니다. 특히 모아의 나무는 잎이 순수하면 100%라고 말하기 쉽습니다.

여기까지의 한계 단서 값은 이미 −1/0/1로 바뀐 것만 넣을 수 있습니다. 실제 주소를 넣어 판정하려면 단서를 뽑는 단계가 먼저 필요합니다(6-4).

6-3중챕터

Colab에서 대회 다시 치르기

코드: 5단계연구실: 재현 절차

아래 다섯 덩어리를 Colab에 차례로 붙여 넣으면 이 대회의 숫자가 그대로 다시 나옵니다. 데이터는 이 저장소에 옮겨 둔 파일(website_phishing.csv)을 읽습니다. 모델 7개 전체와 이상탐지까지 한 번에 돌리는 스크립트는 저장소의 code/01_contest.py입니다.

① 데이터 불러오기

# Colab 첫 셀: imbalanced-learn이 없으면 설치 (Colab에는 보통 들어 있음)
# !pip install -q imbalanced-learn
import pandas as pd
url = 'https://raw.githubusercontent.com/adminmrobo/catch_phishing/main/data/website_phishing.csv'   # 이 저장소에 옮겨 둔 데이터
df = pd.read_csv(url)
print(df.shape)              # (1353, 10)
print(df['Result'].value_counts())   # -1: 702, 1: 548, 0: 103

② 정답 번호 바꾸기 · 시험지 봉인 · 학습용에만 SMOTE

from sklearn.model_selection import train_test_split
from imblearn.over_sampling import SMOTE
SEED = 42
y = df['Result'].map({-1: 0, 0: 1, 1: 2})      # 0 피싱, 1 의심, 2 정상
X = df.drop(columns='Result')
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=SEED, stratify=y)   # 시험지 271개 봉인
X_train_sm, y_train_sm = SMOTE(random_state=SEED).fit_resample(X_train, y_train)
print(y_train_sm.value_counts())   # 세 정답 각 562개

③ 세 출전 모델 학습과 1·2라운드 채점

from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import accuracy_score, f1_score, confusion_matrix
models = {
    '시아 · 로지스틱 회귀': LogisticRegression(max_iter=1000, random_state=SEED),
    '모아 · 의사결정나무': DecisionTreeClassifier(random_state=SEED),
    '하루 · 그래디언트 부스팅': GradientBoostingClassifier(random_state=SEED),
}
for name, m in models.items():
    m.fit(X_train_sm, y_train_sm)          # 학습은 SMOTE 데이터로
    p = m.predict(X_test)                  # 채점은 봉인한 진짜 시험지로
    print(name, 'acc', round(accuracy_score(y_test, p), 4),
          'macroF1', round(f1_score(y_test, p, average='macro'), 4))
    print(confusion_matrix(y_test, p))

④ 3라운드 · 5겹 교차검증 (각 판의 학습 부분에만 SMOTE)

from imblearn.pipeline import Pipeline
from sklearn.model_selection import StratifiedKFold, cross_val_score
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=SEED)
for name, m in models.items():
    pipe = Pipeline([('smote', SMOTE(random_state=SEED)), ('model', m)])
    s = cross_val_score(pipe, X, y, cv=cv, scoring='accuracy')
    print(name, round(s.mean(), 4), '±', round(s.std(), 4))

⑤ 4라운드 · 처음 보는 단서 조합만 따로 채점

seen_keys = set(map(tuple, X_train.drop_duplicates().values))
seen = X_test.apply(tuple, axis=1).isin(seen_keys).values
print('이미 본 조합', seen.sum(), '처음 보는 조합', (~seen).sum())   # 173, 98
for name, m in models.items():
    p = m.predict(X_test)
    print(name, 'seen', round(accuracy_score(y_test[seen], p[seen]), 4),
          'unseen', round(accuracy_score(y_test[~seen], p[~seen]), 4))
시아

라이브러리 버전이 다르면 소수점 셋째 자리부터 조금 달라질 수 있습니다. 이 해설은 scikit-learn 1.9.1, imbalanced-learn 0.14.2로 계산했습니다.

표시 원칙: 데이터 파일로 직접 센 값과 코드를 다시 돌린 값은 코드 재현, 강의 노트북에 찍혀 있던 값은 강의 노트북 값, 설명을 위해 만든 값과 그림은 설명용으로 표시했습니다. 코드 재현 값은 scikit-learn 1.9.1 · imbalanced-learn 0.14.2 기준이며, 버전이 다르면 소수점 셋째 자리부터 조금 달라질 수 있습니다.
