# 검수 보고서 — 가짜 사이트를 잡아라 (피싱 사이트 탐지 연구실)

검수 팩 `TASK_review` 1부 형식 + 2부 R1~R4. 분야: 인공지능(주) · 통계(데이터, 통계 팩 P7 함께 적용). 형식: 대결형 + 대회형(출전·심사·방청). 대상 7쪽 전체. 같은 대화에서 만든 결과물을 스스로 검수했으므로, 다른 대화·다른 모델의 교차 검수를 권장합니다.

## 0. 대상 요약

UCI Website Phishing 1,353개 사이트로 세 출전 모델(시아 로지스틱 · 모아 나무 · 하루 부스팅)이 겨루는 6장 해설. 단서 9개 풀이, 데이터 검진, 예선 누수 적발, 본선 네 라운드, 실전 연습장.
